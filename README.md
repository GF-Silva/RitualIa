Ritualia is a web system developed to break the musical bubble generated by the algorithm of music platforms.

Test access at <http://ritualia.duckdns.org/>

## Installation

The installation tutorials, available for Arch, Ubuntu, and Windows, are in [docs/install.md](docs/en/install_en.md)

## How to use

**Run with:**

``` Bash
flask --app main.py run
```

**In your preferred browser, access:** <http://localhost:5000/>

With the site open, select a musical genre in the main element (Cover-flow) with the genre photos by navigating through the elements using clicks on the desired one or press on the screen (with mouse or touch) to drag. When clicking on one, in the screen that opens, select a desired emotion. The music will open after selection.

This system supports keyboard navigation; to activate it, press TAB on the keyboard. With the main Cover-flow element selected, navigate through it using the left or right arrow keys on the keyboard and press enter to confirm your choice.

## Technology Stack

**Backend:** Python + Flask

**Frontend:** HTML + CSS + JS

## AI Integrations

**Microsoft Azure (TTS):** API used to generate audio explanations of songs given text

**Chatbots:** Chatbots were used as Claude for repetitive tasks (e.g., collecting song data)
